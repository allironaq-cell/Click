# Click Menu (Fabric, MC 1.21.11, client-side)

Build: `gradle wrapper --gradle-version 9.2.1` (once, to generate gradlew + jar), then `./gradlew build`.
Run in dev: `./gradlew runClient`. Output jar: `build/libs/clickmenu-1.0.0.jar`.

Config: `config/clickmenu.json`. Open menu: M (rebindable). Default activation key: R.
